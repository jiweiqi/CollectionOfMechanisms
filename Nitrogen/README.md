## Notes on formats

The `.yaml` files in **Stagni-2023** and **CRECK-NH3** were produced by running
`ck2yaml` (Cantera 3.2.0) on the CHEMKIN files sitting beside them, so they can be
regenerated from source at any time. No `.cti` is provided for these entries —
that format was removed in Cantera 3.0.
